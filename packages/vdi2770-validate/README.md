# `vdi2770-validate` — renamed to `vdi2770`

Installing this installs [`vdi2770`](https://pypi.org/project/vdi2770/), which is
the same project under its own name. Nothing else is in this distribution.

```
pip install vdi2770        # what you want
```

Everything that worked under the old name still works: the `vdi2770-validate`
command, the `vdi2770` command, and `import vdi2770_validate`. They come from
`vdi2770` — this package only makes sure the name you already typed keeps
finding it.

Source, changelog and issues:
<https://github.com/dev365code/vdi2770-validate>.
