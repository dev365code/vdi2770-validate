What this page is

The report it shows is what vdi2770-validate check --no-bundle FILE prints at a command line, and the JSON report is what the same command prints with --json, byte for byte, with the exit code it would return. The page runs that command's own code, in a Python that runs inside the browser and travels inside this file, together with the rules, the reader and the schema they check against. Nothing is fetched to start it.


The file can be saved and opened again from a disk, with no network at all.
